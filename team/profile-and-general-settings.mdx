### Edit your profile

1. Go to **Settings → Profile**.
2. Click **Edit** next to **Personal Information**.
3. Update the fields and click **Save**.

| Field | What to enter |
| --- | --- |
| First Name | Required. |
| Last Name | Optional. |
| Company Name | Required. At least 2 characters. |
| Company Website | Required. A full URL, for example `https://example.com`. |
| Phone / Contact Number | Optional, for example `+1 555 123 4567`. |
| Telegram | Optional, for example `@username`. |
| Email | Can't be edited here. Change it on the Security page. |

To change your photo, hover over the avatar and click **Upload photo**. Use an image file under 5 MB. Click **Remove photo** to delete it.

### Change general settings

1. Go to **Settings → General settings**.
2. Click **Edit** next to **Application Preferences**.
3. Change the settings and click **Save Changes**.

| Setting | Options |
| --- | --- |
| Conversion registration time reporting | **Visit timestamp** or **Postback timestamp** |
| Default report time zone | Search and pick a time zone |
| Default main page | **Dashboard** or **Performance** |
| Default HOME screen | **Campaign report** or **Last opened global report** |
| Default tab in campaign form | **General**, **Destination** or **Last opened** |
| Enable simple campaign form | Use a simplified interface for creating campaigns |
| Default currency | Pick a currency, for example **USD - US Dollar** |

If you leave the page with unsaved changes, you can choose **Discard Changes** or **Update Settings**.

### FAQ

**What does Conversion registration time reporting change?** It decides which time a conversion is reported under: the time of the original visit, or the time the postback arrived.

**The simple campaign form doesn't let me set path weights. Why?** The simple form spreads weights evenly when you save. Use the Advanced campaign form for custom weights.
