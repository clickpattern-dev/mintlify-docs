### Open a report

1. Go to **Performance** in the sidebar. It opens on **Campaigns**.
2. Pick a tab: **Campaigns**, **Offers**, **Landers**, **Flows**, **Traffic Sources**, **Affiliate Networks**, **Conversions** or **Country**.
3. Set the date range in the toolbar. See "[Date ranges, comparison and time zone](/reports/date-ranges-comparison-and-time-zone)".

The **Conversions** tab has a menu. Choose **Conversions** for the list of conversions, or group them by **Click ID**, **Transaction ID**, **External ID** or **Postback Param 1**–**5**.

### More reports

Three buttons to the right of the tabs open more reports:

| Button | Reports |
| --- | --- |
| **Day Parting** | Hour of Day, Day of Week |
| **Devices** | Device Types, Brands, Models |
| **More reports** | Connection (Connection type, ISP / Carrier, Mobile carrier, Proxy), Date (Day, Month), OS (OS, OS versions), Browsers (Browsers, Browser versions), Traffic type, Tracking domain, Advanced |

When one of these reports is open, the button shows its name instead.

**Advanced** opens **Advanced Reports**, where you can request a **Big Data Report** or set up **Scheduled Reports for Data Visualisation**. See "[Scheduled reports](/reports/scheduled-reports)".

### Toolbar

| Control | What it does |
| --- | --- |
| **Search...** | Shows only rows whose name contains your text. Not case-sensitive. |
| Date range and arrows | Sets the period. The arrows move to the previous or next period. |
| Refresh (circular arrow) | Reloads the data. |
| Chart switch | Shows or hides the charts above the table. |
| Share (share icon) | Copies a share link to this exact view. See "[Search, filters and share links](/reports/search-filters-and-share-links)". |
| Currency | Shows money values in the currency you pick. |
| Rows per page | **25**, **50**, **100**, **250** or **500**. The default is 500. |
| Page arrows | Move between pages, or type a page number. |

The currency you pick stays for your session and also applies to the Dashboard. Your default comes from **Settings → General settings → Default currency**.

### Act on selected rows

Tick the checkbox on one or more rows, then use the buttons above the table:

| Button | What it does |
| --- | --- |
| **View** | Opens the selected item. On reports like Country it opens that item's report in a new tab. |
| **Edit** | Opens the item for editing. Inside a detail tab it reads, for example, **Edit Offer**. |
| **Clone** | Makes a copy of the item. |
| **Tags** | Adds or removes tags. Campaigns, offers and landers only. |
| **Update Cost** | Sets cost manually. Campaigns tab only. |
| **Actions** | **Pause**, **Resume**, **Archive** or **Unarchive**, **Move to workspace…**, and **Anti-fraud** where available. |

**View**, **Edit** and **Clone** need exactly one selected row. Hover a disabled button to see why it's unavailable. Editing needs the Editor role or higher.

### Double-click to drill in

Double-click a row to open a detail tab for that item. For example, double-clicking a campaign shows its offers. See "[Grouping and drill-down](/reports/grouping-and-drill-down)".

### Sort and filter

- Click a column header to sort. Reports open sorted by **Profit**, highest first.
- Use the filter icon on a column to filter rows. See "[Search, filters and share links](/reports/search-filters-and-share-links)".
- The totals row at the bottom adds up only the rows that match your search and filters.

### FAQ

**Why is a row named "(Unknown)" or "(Not set)"?** That row groups visits where the value was empty, such as a missing device brand.

**Why can't I double-click into Hour of Day or Day of Week?** These reports can't filter a child report, so double-click does nothing there.

**What does double-clicking a deleted item do?** You'll see "This entity was deleted — drill-down is unavailable."
