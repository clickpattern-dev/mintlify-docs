---
title: "Glossary"
description: "Short definitions of the terms used across ClickPattern."
---

| Term | Definition |
| --- | --- |
| **Affiliate network** | The network you get offers from. It sends conversions back by postback. |
| **Auto payout** | Offer setting that takes the payout from each postback or pixel. |
| **CAPI (server-side conversions)** | Sending conversions from ClickPattern straight to an ad platform's server so it can optimize. |
| **Campaign** | What you put in your ad. It ties a traffic source to landers and offers and gives you a campaign URL. |
| **Campaign URL** | The tracking link for a campaign, `https://{domain}/c/{campaign ID}`. |
| **Click** | A visitor clicking from your lander to an offer. |
| **Click ID** | ClickPattern's unique ID for each visit, passed with `{clickid}` and returned in the postback. |
| **Conversion** | A sale, lead or other result reported by postback, pixel or integration. |
| **Cost source** | Where a campaign's cost comes from: Not Tracked, Manual, Token (Auto) or API (Integrated). |
| **CTA** | The call-to-action link on a lander that sends the visitor to an offer. |
| **Custom conversion event** | An event type you define, such as a signup, that you can count separately. |
| **Dimension** | A way to group a report, such as Country or Device Type. |
| **Direct tracking** | Tracking without a redirect: your ad links to the page and a script records the visit. |
| **Event type** | The kind of conversion, sent as `et`, for example `lead` or `purchase`. |
| **External ID** | The traffic source's own click ID, for example a platform's click parameter. |
| **Flow** | Reusable routing rules that decide which landers and offers a visitor sees. |
| **Integration** | A connection to an ad platform or store, such as Meta, Google Ads or Shopify. |
| **Lander** | A page shown before the offer. |
| **Manual payout** | Offer setting that uses a fixed payout, or a payout by country. |
| **Mapping** | Linking a platform campaign to a ClickPattern campaign so cost and rule actions apply. |
| **MCP** | A standard that lets AI assistants read and act on your ClickPattern data. |
| **Offer** | The product or page you promote and get paid for. |
| **Offer cap** | A limit on conversions or clicks for an offer, with an optional redirect offer. |
| **Path** | One route in a campaign or flow: a set of landers and offers with weights. |
| **PatternPilot** | ClickPattern's automation rules that pause, resume or adjust campaigns based on metrics. |
| **Pixel** | A conversion image or script placed on a thank-you page. |
| **Postback** | A server-to-server message from a network to ClickPattern reporting a conversion. |
| **Public Workspace** | The shared workspace for elements every private workspace can use. It can't hold campaigns. |
| **Redirect tracking** | Tracking where the visitor passes through the campaign URL before reaching your page. |
| **Refund** | A negative event that reverses a conversion's revenue. |
| **Rule** | A PatternPilot automation: conditions plus actions. |
| **Token** | A placeholder in braces, such as `{country}`, replaced with visit data. |
| **Tracking domain** | The domain your tracking links use. |
| **Traffic source** | Where you buy traffic, such as an ad network. |
| **Transaction ID** | The network's ID for a sale, sent as `txid`. |
| **Unique visit** | The first visit from a visitor within the uniqueness window. |
| **Visit** | A visitor arriving at your campaign URL or tracked page. |
| **Workspace** | A container for campaigns, elements and team members. |
