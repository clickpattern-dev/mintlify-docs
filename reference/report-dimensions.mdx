---
title: "Report dimensions"
description: "The options in the grouping dropdowns above the Performance table. Up to four levels."
---

### First level and below

| Category | Dimensions |
| --- | --- |
| Entities | Campaigns, Offers, Landers, Flows, Traffic Sources, Affiliate Networks, Rules, Conversions |
| Tracking | Click ID, Transaction ID, External ID, Postback Param 1–5 |
| Geo | Country |
| Time | Hour of Day, Day of Week, Day, Month |
| Device | Device Type, Brand, Model |
| Network | Connection Type, ISP / Carrier, Mobile Carrier, Proxy |
| Software | OS, OS Version, Browser, Browser Version |
| Other | Traffic Type, Tracking Domain |

### Second level and below only

| Category | Dimensions |
| --- | --- |
| Entities | Paths |
| Tracking | V1–V10 (custom variables 1–10) |
| Geo | State / Region, City, Language |
| Other | Referrer, Referrer Domain |

### Fixed combinations

| First level | Allowed second level |
| --- | --- |
| Click ID, Transaction ID, External ID, Postback Param 1–5 | Conversions only |
| Tracking Domain | Campaigns only, no third level |

Which options appear under each entity depends on the first-level choice.
